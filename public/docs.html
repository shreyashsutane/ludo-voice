Page 05 / Core Engine Rules

Universal Ludo Game Engine & State Machine

Mathematical coordinate mapping, legal move calculation, and capture logic.

📐 Coordinate Translation Mathematics

A single progress integer p represents every token's journey:

p = -1: Inside Yard (inactive starting base)
p = 0..50: Outer track cells (52 cells total)
p = 51..55: Home stretch column leading to center
p = 56: Finished inside Home Triangle (Won)
absCell(color, p) = (START[color] + p) % 52

⚙️ Rule Execution & Automove Algorithm

  • 1. Starting a Token: Rolling a 6 unlocks a token from the yard (-1 → 0) and grants an immediate bonus roll.
  • 2. Captures & Safe Zones: Landing on an opponent sends their token back to yard (-1) unless on a Safe Star cell. Capturing grants a bonus turn.
  • 3. Exact Finishing Requirement: Tokens must land exactly on cell 56.
  • 4. Smart Automove Heuristic:
    shouldAuto = legalMoves.length === 1 ||
      (legalMoves.length > 1 && allTokensInYard)

Page 10 / Production & Security

Production Hardening, Security & Deployment

Enterprise edge protections, automated CI/CD, and visual regression testing.

🛡️ Security Hardening Protocol

  • Sliding Rate Limiter: Closes socket with code 1008 if requests exceed 120 / 10s.
  • Payload Sanitization: All strings pass through regex filters stripping control characters and HTML tags.
  • Authoritative Edge Validation: Moves and rolls validated on Durable Object.

🚀 Edge Deployment Topology

  • Cloudflare Workers: Edge runtime deployment with zero container overhead.
